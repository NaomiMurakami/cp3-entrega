# Checkpoint 3 - Site Pessoal

Projeto desenvolvido para a disciplina de Front-End / Web Development.

## Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Flexbox e Grid)
- JavaScript (Alternância de Tema Claro/Escuro com LocalStorage)

## Funcionalidades
- Navegação entre páginas (Início, Currículo, Contato, Multimídia, Gráficos)
- Suporte a Modo Escuro (Dark Mode)
- Tabela responsiva de habilidades
